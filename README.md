# ahora.nl

Now LIVE: [ahoranl.streamlit.app](https://ahoranl.streamlit.app)

Dutch people that want to learn Spanish can now do so by reading the daily **Dutch** news in at their level of Spanish. Ahora.nl (a play on nu.nl) is a news site that takes existing Dutch news articles from nos.nl and uses open-source LLMs to translate them to Spanish at various difficulties (A1, A2, B1, B2, C1, C2).
